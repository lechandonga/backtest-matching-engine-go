# 本地验证

一条命令跑完全部自动化用例（含业务分组统计输出）：

```bash
make verify
```

等价于：

```bash
go test ./... -count=1 -v
```

只看业务分组汇总（不用 -v 时汇总表依然打印）：

```bash
go test ./... -count=1
```

大回放基准（约 3 万条事件、5 个交易日、8 个标的）：

```bash
go test -run '^$' -bench Replay30k -benchtime=3x ./engine
```

并发安全检查（需要 cgo）：

```bash
CGO_ENABLED=1 go test -race -count=1 ./...
```

## 用例分组

测试结束后会按业务打印每个组的用例数与通过/失败数：

| 分组 | 覆盖内容 |
| --- | --- |
| `01-legacy-compat` | 旧拒单原因/状态流转、幂等、乱序确定性、资金持仓不足、市价单、撤单 |
| `02-trigger-orders` | 止损/止损限价/跟踪止损、只触发一次、锚点单向、触发瞬间不足、待触发撤单、乱序重复、标的隔离 |
| `03-time-in-force` | FOK 全成与全不成（含触发组合）、IOC 剩余释放、GTC 挂簿、非法 TIF |
| `04-trading-day` | 日终过期（挂单/条件单）、重复收盘幂等、失效后拒绝、跨日盯市对账、并发顺序无关、按标的隔离 |
| `05-replay-perf` | 3 万事件 / 5 交易日确定性回放（串行 vs 并发投递结果一致）、耗时/内存基准 |
