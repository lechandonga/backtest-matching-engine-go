# 交易日边界：收盘、日终快照与跨日盯市

## 收盘事件（`KindDayClose`）

字段：

- `Symbol`：按标的独立收盘；不同标的互不影响。
- `TradingDay`：交易日序号（建议从 1 起单调递增）。填 0 时由引擎按收到顺序推断。
- `ClosePrice`：收盘价。`> 0` 时更新该标的盯市价；`<= 0` 表示只做收盘不改盯市价。

一个收盘事件依次完成：

1. 校验交易日序号：同一标的上 `TradingDay` 不允许倒退，倒退返回
   `STALE_TRADING_DAY`。
2. `ClosePrice > 0` 时把最新价 / 买价 / 卖价 / 盯市价统一更新到收盘价。
3. 该标的的 `DAY` 委托批量失效：
   - `WAITING_TRIGGER` 的当日条件单（未触发）；
   - `NEW / PARTIALLY_FILLED` 的当日挂单（未成交完）。
   - 失效订单进入 `EXPIRED`，冻结资金 / 冻结持仓一次性退回，
     不产生成交、不重复退钱退货。结果在 `Result.ExpiredOrderIDs` 中返回。
4. GTC 单（含 GTC 条件单）不受影响，隔夜继续挂着 / 继续等待触发。

## 幂等

- 收盘事件本身走全局 `EventID` 幂等：相同 `EventID` 重复投递返回首个结果。
- 同一 `(Symbol, TradingDay)` 即使换了 `EventID` 重复收盘，也**不会**
  二次失效、二次释放冻结、二次改动盯市价，返回的 `ExpiredOrderIDs` 为空。
- 已 `EXPIRED` 的订单不会被二次失效；对其撤单返回 `ORDER_EXPIRED`，
  对其再投递任何行情都不会成交。

## 跨日盯市与权益拆解

- 持仓跨日保留，第二天新的行情/收盘价继续更新盯市价，浮动盈亏连续累积，
  已实现盈亏不重算、不回滚。
- 账户恒等式在每个事件后校验，跨日也不例外：

```
权益 = 现金 + 冻结现金 + Σ(可用持仓 + 冻结持仓) × 最新价
     = 初始资金 + 已实现盈亏 + 未实现盈亏 − 累计费用 + 公司行为调整
```

拆不平时 `Snapshot()` 返回 `portfolio.ReconcileError`，引擎不会静默吸收。

## 同一账户自撮（内部记账）

回测里同账户自己的买卖单可能互相成交。此时两腿价款净额为 0、两腿费用照扣、
总股数不变（可用 +qty、冻结 -qty），卖腿按成交前均价结转已实现盈亏，
买腿把成交价并入成本基，由 `portfolio.FillSelfCross` 在一把锁内原子记账，
避免先改均价再结转导致的权益拆不平。

## 并发与顺序

`Submit` 只入缓冲、不改变状态；`Drain()`/`Process()` 取出缓冲后按
`(Seq, EventID)` 稳定排序再顺序应用。因此日终批量失效与行情、成交流、
委托事件即使并发到达、乱序到达，最终账户与订单状态只取决于事件内容，
不取决于到达顺序。`go test -race` 通过。
